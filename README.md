# Student Success and Career Guidance Platform

A Streamlit-based final year project that combines:

- dropout risk prediction for admins
- psychometric assessment for students
- future-oriented career recommendations with roadmap guidance

## Current milestone

This version includes the project skeleton, authentication, SQLite database setup, role-based navigation, seed data, and initial student/admin dashboards.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
